# 🎲 Dice Rolling Game

A simple Python dice rolling game using the random module.

## Features
- Rolls two dice randomly
- Displays dice values
- Calculates total score
- Allows multiple rolls

## Technologies Used
- Python

## Concepts Used
- Loops
- Conditional Statements
- Random Module
- User Input Handling

## How to Run

bash
python main.py
